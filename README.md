# Orah-Lore
تضعك لعبة "الحياة الواقعية" (Orah RP) في محاكاة متكاملة داخل ولاية أورا. تبدأ بشخصية جديدة ومبلغ ضئيل لتبني مستقبلك ملتزماً بقوانين واقعية.  تتنوع المسارات بين الوظائف المدنية، القطاعات الحكومية كالشرطة والإسعاف، أو العالم الإجرامي، مع اعتماد كامل على تفاصيل دقيقة كالمؤشرات الحيوية، التواصل الصوتي، وصيانة المركبات والأسلحة.
